# Retrospective, cycle ending 2026-08-26

Fourteen commits. One correction that mattered more than any of the features.

---

## What went well

**The Quest became a thing a stranger can actually use.** A first time visitor
now gets one sentence and one button pointed at a fixed zone, instead of a
progress bar reading 0 of 114 and three modes to choose between. The method is
taught inside the work, one plain verb line per pass, in an order the app will
not let you break. After one entryway a person has done Sort before Straighten
without ever reading a definition. That is the mechanism Phil asked for.

**The offer stopped counting browsing as commitment.** It used to fire at three
cards in a session. Ten cards scattered across ten rooms is somebody looking
around; six cards in one place is somebody who finished something. The trigger
is now zones held and rooms touched. The first zone held offers nothing at all,
by rule, because that is the moment the method lands and an offer there
interrupts the win.

**Two agents worked the same file without damaging each other.** The nightly
cloud routine deep linked zone pages into their own zone run while this session
built the first run gate. Both landed, both survived the rebase, and the merged
behaviour is right: a deep linked newcomer skips the gate, because arriving from
a zone page already is a choice.

**Browser testing earned its cost again.** A code read passed the first run
gate. The live page showed an install prompt and a deck link sitting on what was
supposed to be a one button screen. The install prompt was the interesting one:
the gate hid it correctly and the `beforeinstallprompt` handler unhid it
milliseconds later. No amount of reading the gate would have found that, because
the gate was not wrong.

---

## What did not go well

**I called the image programme an import problem, and it was not.** I told Phil
the site used 41 of about a thousand images and that I had the whole thing
misfiled as blocked on generation. The audit found the 41 in use are the
survivors of an editorial QA pass recorded in 35 files sitting beside the
images, with written reasons: fake QR codes, baked em dashes, trademarked
packaging, claims contradicting the book. Ch36 lost 16 of 20 plates to QR codes
alone.

The failure was not the wrong conclusion. It was announcing a conclusion drawn
from a file count before anybody had opened a file. A thousand images in a
folder tells you nothing about whether any of them are usable, and I reported
it as if it did.

Three routes closed on inspection, all of which I had implicitly counted:

* the 94 shop photographs are a sheet metal floor with an identifiable client
  and one unobscured human face, so they are RED band and cannot be published
* the 90 deck images are trading card mockups with game chrome, and the live
  printable deck already ignored them for that exact reason
* chapters 40 to 50 have zero images, not zero clean ones, so the eleven
  uncovered rooms were never a sourcing problem at all

**A generator was about to delete both imported figures.** `build_zone_pages.py`
rewrites all 114 zone pages from scratch. I hand wired two figures into two of
them and would have shipped that. This is the second time in this repository a
generator has been one run away from erasing the only copy of something added by
hand; `build_resources.py` and the links to 134 pages was the first. Twice is a
pattern, not bad luck.

**The offer's button contradicted its own sentence.** The CTA was hardcoded to
the $19 pack, so my new free deck pitch would have read "free, no email needed"
directly above a button asking for nineteen dollars. Caught in testing rather
than in review, which is later than it should have been for a trust defect.

**Revenue is still $19.** Nothing this cycle produced a visitor.

## What to change next cycle

1. **Open a file before reporting a count.** Any claim of the form "N of these
   exist and we use M" is not reportable until a sample has actually been read.
   This cost a wrong headline to the owner and a backlog item written on a false
   premise.

2. **Before hand editing any file under `site/`, check whether a generator owns
   it.** `ls ops/build_*.py` and grep for the path. If one does, the change goes
   in the generator or is chained to it. This is now done for the figures, but
   the rule is what prevents the third occurrence.

3. **When copy and control disagree, that is a P0, not a polish item.** A free
   offer above a paid button is the same class of error as a false price. Check
   the pair whenever either changes.

4. **Stop counting the catalogue as progress.** 164 products exist and 155 of
   them cannot be bought, because they have no Stripe links. Until that is true
   they are inventory in a spreadsheet. Next cycle either wires them or stops
   listing them as an achievement.

5. **The constraint has not moved.** A better Quest, a corrected image plan and
   a five item nav are all real improvements to what happens after somebody
   arrives. 3.4 visitors a day still arrive. Gates G1, G2 and G5 stand exactly
   as written, and a good week is not an argument for relaxing them.
