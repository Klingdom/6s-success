# Retrospective, cycle 33 (2026-08-31)

## What this cycle did

Turned yesterday's mobile MVP from a claim into something Phil can hold.

Yesterday I committed an app and a content pipeline. That was code which had
never been built and never been served. This cycle proved each step before
taking the next:

  dependencies resolve   1,131 packages, 47 seconds
  the app compiles       539 modules, a 1.73 MB Hermes bundle
  Metro serves it        packager-status:running, manifest 200 over the LAN,
                         serving the real app bundle

So the Home Quest is installable on a real phone through Expo Go today, with no
Apple membership, no Google Play account and no native toolchain.

Also sent Phil two reports he asked for, on the apps and on image and video, and
both were built from figures measured during the writing rather than recalled.

## What went well

**"It bundles" is a different claim from "it exists", and I checked.** The
temptation after writing an app is to describe the loop and move on. `npx expo
export` is thirty seconds and turns an assertion into 539 modules and a byte
count. It could have failed on any of a dozen things and did not.

**The content pipeline held up under its first real use.** The app's corpus is
generated from the website's, records the source hash, and has a check mode.
Building it cost about the same as copying the file would have, and it is the
difference between two products that teach the same thing and two that drift.
Twelve days of a stuck MCP image publish is what the alternative looks like.

**The media report told the truth about video.** The tooling is real: ffmpeg
8.1.1 with libass and zoompan, three written pipelines, one of them photo led
now that 110 zones carry a reviewed picture. Zero episodes exist. It would have
been easy to describe that as a capability. Zero of 114 is the honest number and
it is the one I sent.

**I named a decision rather than quietly making it.** The only narration voice
here is Windows SAPI and it is robotic. For a brand whose promise is warmth, a
synthetic voice reading somebody's home instructions is worse than no video.
Captions only unblocks all 114 videos at zero cost; a real voice is better and
slower. That is Phil's call and I said so instead of picking.

## What did not go well

**The lockfile was nearly left out.** 1,131 packages resolved on this machine
and the commit initially carried no `package-lock.json`, which means the next
install resolves a different tree and "it bundled here" stops meaning anything.
Caught it in `git status`, not by thinking.

**A dev server that dies with this session is a thin kind of done.** Metro is
running now and Phil can scan a QR code now, but the moment this session ends
he is back to a command. The README carries the command, so it is recoverable
rather than lost, but I should not describe a running process as a delivered
capability.

**Nothing moved revenue, for the twelfth cycle.** The app is real and the shop
still cannot take a payment. Day eight of a deploy nobody but Phil can press.

## What to change next cycle

1. **Test the loop on the device rather than in node.** I proved the selection
   and completion rules against the real corpus in a node script, which is
   sound but is not the app. The next honest step is 5B.4: draw, done, stop,
   resume and zone finish exercised in Expo Go.

2. **Web to mobile import is the highest value unblocked item left.** A person
   with progress in the browser losing it on install is the worst possible
   first impression of the app, and the backup file already exists.

3. **Stop starting long lived processes as deliverables.** Either make it
   survive, or hand over the command and say plainly that is what it is.
