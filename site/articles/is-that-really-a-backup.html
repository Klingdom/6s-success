Sort, and the test most "backups" never actually pass

Is that really a backup, or are you just storing it?

The old printer, the second vacuum, the phone with the cracked screen in the cable drawer. Each one earned its spot in the house with the same word, backup, and none of them have been checked since. Here is the one question that tells a real backup apart from an object you are quietly storing on its behalf.

The short answer. A backup is only a backup if it has actually covered for the main one, recently, or if you could press it into service right now without finding out first that it is dead, dried out, or out of date. Test it today. If it passes, give it a real home and a maintenance habit. If it fails, it was never a backup, it was a large object you were storing, and it can leave.

The word that closes a question instead of answering it

"Backup" is one of the most useful words in a household, and one of the most misused. Calling something a backup sounds responsible, so it gets applied fast, to the printer that still has ink in it, the vacuum that still spins up, the phone that still turns on if you find the right charger. The word closes the question rather than answering it: nobody has to decide whether the object earns its space, because it already carries a label that answers for it.

The trouble is that a label is not a test. An object can carry the word backup for years without ever once doing the job the word promises, ageing quietly in a corner or a drawer while the thing it supposedly backs up keeps working fine on its own. The day the main one actually fails is the first time anyone finds out whether the backup still works, and that is exactly the day you cannot afford to find out.

The one question that decides it

There is a single test that separates a real backup from a stored object, and it does not require guessing about the future. Ask about the past and the present instead: has it actually covered for the main one, within roughly the last year, or could it cover right now, today, without you finding out first that it does not work? A spare that has never once been called into service and has never been checked is not proven either way. It is a hope, not a backup, and a hope does not need a permanent spot in the room.

This is not a trick question and it does not need imagination. It needs five minutes: plug it in, switch it on, run it, print on it, charge it and check it still holds charge. The test either passes or it does not, and either answer is useful, because either answer lets you stop treating an untested object as if it were a settled decision.

Three "backups" in three rooms, and none of them had been checked

This pattern is not one household's habit. It shows up in the same shape in at least three different rooms of an ordinary home, each with its own object and its own excuse, and each time the fix is the same five minute test.

The printer in the home office. An old printer sits in the corner or on the floor of the cupboard because it might be a backup. The test is immediate: plug it in and print a test page right now. If it prints, and you are prepared to keep a spare cartridge for it in stock, it is a backup, and it earns a real home in the room rather than a tolerated corner. If you will not plug it in today, it was never a backup, it is a large object nobody has decided about, and the honest next step is electronics recycling this week, along with any sealed cartridges that no longer match a machine anyone owns.

The second vacuum in the mudroom. The old machine is still there because it works, roughly, and getting rid of something that works feels wasteful. Meanwhile it holds the corner and the newer one lives in the walking line, the exact opposite of what a backup should cost you. The test: in the last year, did the main vacuum ever break down for long enough that you went and got this one out? If the answer is no, it is not a backup, it is a machine you are storing on behalf of a future that has not asked for it, and it can go to someone who has no vacuum at all.

The old phone in the charging drawer. This one deserves its own section, because it usually carries two reasons at once, and the two quietly contradict each other.

Why the old phone is the hardest case, and how to split it

The retired phone in the charging drawer is almost never kept for one reason. It is kept as a backup in case the main phone breaks, and as an archive because there are photos on it that have never been moved anywhere else. Those are two different jobs, and one object cannot do both well, which is why, in practice, it usually does neither.

Run the backup half through the same test as everything else: charged and switched on within the last year, or it was never really covering for anything, it just looked like it was. The archive half needs a different fix, because no amount of charging solves it. Transfer the photos today, while the device is already in your hand and the charger is already out, or say out loud that you never will and mean it. Either the photos end up safely somewhere else and the phone can be recycled with the battery still inside, or the phone earns a real slot as a tested, working backup on its own merits, not because it also happens to hold pictures nobody has moved.

Why this costs more than a corner

An untested backup does not just take up space, it takes the space that matters most, often sitting closer to the door, the outlet, or the shelf than the object actually in daily use. That pushes the thing you reach for every day into a worse spot, the same mechanism behind why the item you use daily so often ends up the hardest one to get to. There is a safety cost too: a dead spare vacuum still has a cord and a plug, an unused printer in a closed cupboard still needs airflow around its fuser, and a phone left flat in a drawer for years is a battery nobody is checking, where swollen or hot is a stop now problem, not a someday one. An object that earns no use also earns no attention, exactly the wrong pattern for anything with a cord, a motor, or a battery in it.

The five minute test, room by room

You do not need a whole session to run this. It fits inside whatever reset you were already doing in that zone.

  • Sort. Find every object in the house currently wearing the word backup, spare, or just in case, without having been checked in the last year.
  • Straighten. Move each one to where the test can happen right now, out of the cupboard or drawer, plugged in or charged.
  • Shine. While it is out, this is also the moment you actually look at it closely for the kind of wear that only shows once something leaves its corner.
  • Safety. Check the cord, the battery, and the plug while it is in hand. A backup nobody has touched in years is the one most likely to have a problem nobody has noticed.
  • Standardize. Run the actual test, plug in, power on, print, or charge, whatever proves the object's job. Write down the date, so the next test has a starting point.
  • Sustain. Attach the re-test to something that already happens yearly, a device upgrade, the smoke alarm battery change, a spring clean, so a proven backup does not quietly drift back into an unexamined one.

What to do with what you find

The test only ever produces two honest outcomes, and both are progress. If the object passes, give it a real, named spot rather than a tolerated one, and put the re-test date somewhere you will actually see it. If it fails, treat that as the answer rather than a reason to test it again next month. A spare that still works but that nobody will maintain is worth real money now, sold or passed to someone with none at all, and worth nothing later, so move it the same week you find it. A spare that no longer works goes to proper electronics recycling, with any battery left inside rather than pried out and left loose in a drawer.

Before you start. This is guidance for organising and cleaning a home. It is not instruction for electrical, gas, structural, or any other licensed work. Common questions

How do you know if something is actually a backup?

Ask whether it has actually covered for the main one, recently, and not whether it theoretically could. A spare vacuum, printer, or phone is only a backup if you can point to a real day it was pressed into service, or if you could press it into service right now without finding out first that it is dead, dried out, or out of date. If neither is true, it is not a backup. It is an object you are storing on behalf of a future that has not asked for it.

Why do we keep things we call backups but never use?

Because calling something a backup closes the question without answering it. The word sounds responsible, so it is easy to apply to anything that still technically works, and once applied it rarely gets checked again. The item keeps its spot in the room by title rather than by performance, sometimes for years, while the actual insurance it was meant to provide quietly expires.

Should I keep my old phone as a backup?

Only if you actually maintain it as one: charged, switched on, and tested within the last year, so it would work the day you needed it. If it has sat dead in a drawer, it is not a backup, it is flat and out of date, and it will not help you on the day your main phone fails. A phone you are keeping for the photos on it is a different job, an archive, not a backup, and it needs its own deadline: transfer the photos today, while the device is in your hand, rather than storing the whole phone indefinitely.

Is it worth keeping a spare vacuum, printer, or appliance?

Only if it earns the space it holds. A spare vacuum is worth keeping if the main one has genuinely broken down for long enough, within the last year, that you went and got the spare out. A spare printer is worth keeping if you would print a test page on it today and are prepared to stock a cartridge for it. If either answer is no, the honest description is not backup, it is a large object taking up a corner while the thing you actually use lives in the walking line.

What should I do with a backup that fails the test?

Let it go the same day you test it, not on a future weekend. A working spare that nobody will maintain sells for real money now and for nothing later, so list it or pass it to someone who has none at all. A spare that no longer works, a dead phone, a printer that will not print a test page, goes to proper electronics recycling, with the battery still inside rather than pulled loose in a drawer.

How often should you re-test a backup?

Once a year is enough for most household backups, and it works best attached to something that already happens on a schedule, a device upgrade, a spring clean, the day the batteries in the smoke alarms get changed. A backup that is never re-tested slowly turns back into an unexamined object, which is exactly the state the test was built to catch in the first place.
