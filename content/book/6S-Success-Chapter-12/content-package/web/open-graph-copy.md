## Variant A (the Home Test hook)

- og:title: A Place for Everything, So Everything Can Find Its Way Back
- og:description: A home works when putting the thing back is easier than putting it down anywhere else. If returning it takes more than one easy motion, the home is wrong, not you.
- twitter:title: A Place for Everything, So Everything Can Find Its Way Back
- twitter:description: The second S gives every keeper one clear home, a single spot where it lives and returns to. The only test a home has to pass is an easy return. From Chapter 12 of 6S Success: Home Edition.
- og:image concept: The Home Test as a contrast. On the left, a set of keys drops into a tray by the door in one green, effortless arc, marked "one motion," and the keys go back. On the right, the same keys face a home that is far, behind a door, and under a lid; the path is long and broken, marked "three steps and a decision," and the keys never make it there. A single line runs beneath: is putting it back easier than setting it down where you stand?
