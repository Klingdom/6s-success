## Hero device: The Use Test
Chapter 8 handed the reader one gate, does this help the space do its job, judged by belonging. Chapter 9 turns to what passed and asks a narrower gate judged by use: when did you last use it. A fast, specific memory of the last time it worked marks it necessary; a shrug or an invented scenario marks it unnecessary. For the genuinely hard cases, a tiebreaker that strips sunk cost: if it vanished today, would you buy it again. The Use Test catches two patterns: the just-in-case trap (a plausibly useful thing kept for a rare someday) and duplicates/surplus (you need one, not several).

## Motifs
- **Useful is not used.** Usefulness is a claim about the future; use is a fact about the past. A test that keeps everything useful keeps everything.
- **Necessary includes a sensible quantity.** One good umbrella is necessary; the third is surplus.
- **Letting go is not wasting.** The sunk cost is already spent; keeping the unused only charges rent in space and attention.
- **The needle steps again, shorter.** Objects moved, so the meter moves; a smaller surplus left, so the step is smaller.

## Emotional purpose
Quiet relief without shame. The reader releases useful-but-unused things and is protected from the sunk-cost guilt that stalls most passes. Unnecessary is framed as a reading of behavior, not a verdict on the object or the owner. Letting go is catching up to a truth that already changed, not confessing a mistake.

## Practical purpose
Teach the reader to run a Use Test on what a Sort pass leaves behind: keep what gets used, set the just-in-case surplus in an out box, thin duplicates to a sensible quantity, park the honest maybes separately, and do it all without deciding the out box's fate or where the keepers get stored.
