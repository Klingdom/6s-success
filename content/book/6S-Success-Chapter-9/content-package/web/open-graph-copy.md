# Open Graph and Twitter Card Copy: Chapter 9, Necessary vs. Unnecessary

Two variants. Use the og:image concept noted under each.

## Variant A (the Use Test hook)

- og:title: When Did You Last Use It?
- og:description: Everything left after your first pass belongs here. That is not the same as needing it. Run the Use Test on each thing: when did you last use it? Keep what you use, set the rest aside.
- twitter:title: When Did You Last Use It?
- twitter:description: Useful is not the same as used. One honest question sorts what belongs here by what you actually use. A shrug means it goes in the out box. From Chapter 9 of 6S Success: Home Edition.
- og:image concept: The Use Test gate. A single basket item flows toward a central gate labeled "When did you last use it?" and splits. One branch goes to a green zone labeled "necessary, keep" (the umbrella you grab, the keys, the leash). The other follows an arrow to a slate zone labeled "unnecessary, the out box" (extra umbrellas, surplus tote bags, a dead cable). A small side gate reads "would you buy it again?" Caption line: One question, two outcomes.

## Variant B (letting go is not wasting)

- og:title: Letting Go Is Not Wasting
- og:description: The money was spent when you bought it, and keeping it unused does not earn that back. It only charges you rent in space and attention. Sort by use, not by guilt.
- twitter:title: Letting Go Is Not Wasting
- twitter:description: Holding an unused thing to honor what it cost does not get the money back. The waste, if any, already happened. Letting go is the end of paying twice. From Chapter 9 of 6S Success: Home Edition.
- og:image concept: The reassurance card. A clean card with the line "Letting go of what you do not use is not wasteful," and below it a small unused item beside a light left on in an empty room, showing the sunk-cost comparison rather than a giveaway pile. Footer: Sort by use, not by guilt.
