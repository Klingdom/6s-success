# Read Next Recommendations: Chapter 9, Necessary vs. Unnecessary

1. Chapter 10, Red Tags, Holding Areas, and Sorter's Remorse
   The next step. You have made the clear calls and set the unnecessary things in an out box. Next you need a safe system for the few items you honestly cannot decide, and a way to handle the second thoughts that come after you let something go.

2. Chapter 8, Sort: Remove What Does Not Belong
   The setup. Before this pass could work, you cleared the console of what did not belong at an entryway. That left a basket of things that all belong here, which is exactly what the Use Test sorts by whether you actually use it.

3. Run the Use Test (the chapter action)
   Pick up one thing you have been keeping just in case and ask when you last used it. If you cannot remember, put it in an out box today. One honest release is a full pass.

4. The Use Test card (free resource)
   A printable and phone wallpaper of the one question, when did you last use it, the line "useful is not the same as used," and the "would you buy it again?" follow-up, for quick reference on any space you tackle next.

5. The Necessary vs. Unnecessary sheet (free resource)
   A printable with two columns, what you actually use and what you were keeping just in case, so you can run a clean pass on one space without agonizing over anything.
