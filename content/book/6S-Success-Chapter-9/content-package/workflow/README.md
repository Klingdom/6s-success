## The chapter in one screen

- **Hero device · The Use Test.** Among the things that belong in a space, run one honest question on each: when did you last use it? Used it recently, or you would replace it if it vanished, means necessary, so keep it. Only plausibly useful and kept just in case means unnecessary, so it goes in the out box. The reframe that powers it: useful is not the same as used.
- **The follow-up for hard cases · would you buy it again?** For the genuinely close calls, ask whether you would buy it again today if it vanished. If not, it is unnecessary.
- **The two patterns the test catches.** The just-in-case trap, a plausibly useful thing kept for a someday that rarely comes. And duplicates and surplus, where you need one umbrella, not three. Necessary includes a sensible quantity; the rest is surplus.
- **The worked pass · the drop-zone basket.** Beside the cleared console sits a basket where things that all belong at an entryway have piled up. Run the Use Test on it. Keep one umbrella, one or two reusable bags, the keys, the leash. The out box takes the two umbrellas you never reach for, the wad of surplus tote bags, a spare key to a car you sold, old takeout menus, a dead cable for a phone you no longer own. Everything in the basket belonged there. Most of it was still unnecessary, because you do not use it.
- **The out box is a set-aside spot, not a destination.** Where the unnecessary things go from here, donate, sell, store, recycle, or throw, is Chapter 11. The genuinely uncertain items get a system of their own in Chapter 10. This chapter makes the clear, use-based calls and sets the rest aside.
- **Letting go is not wasting.** The money was spent when you bought it. Keeping it unused does not earn that back; it only charges rent in space and attention.
- **The needle moves again.** A smaller second step toward calm, because there was less to remove on this pass than the first one cleared. Still within the first S, still short of the goal.

## Scope note

Chapter 9 sorts by need, not by belonging. It asks whether you actually use a thing that already belongs in the space. It does not re-ask whether an object belongs there (that was Chapter 8), it does not build a red-tag or holding-area system or handle second thoughts (that is Chapter 10), it does not decide donate, sell, store, recycle, or throw (that is Chapter 11), and it does not teach where to store the necessary things by frequency of use (that is Chapter 13). "When did you last use it" is a keep-or-release signal only. The out box is a set-aside spot, not a destination. The chapter sets up those later decisions without making them.
