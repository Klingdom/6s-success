## Full summary (about 250 words)

Chapter 9 is the second chapter of Part Three and the second Sort question. It opens back at the entryway drop zone, where the console cleared in Chapter 8 is still clear, but the basket that fed it for years is still full. Everything in the basket belongs at an entryway, umbrellas, bags, keys, cables, and yet most of it never gets used. Last chapter asked where a thing lives. This chapter asks whether you need to keep it at all.

The core insight is that almost everything you own is useful in some imaginable circumstance, so usefulness passes everything, and a test that passes everything is not a test. The line that carries the chapter is that useful is not the same as used. Useful is a claim about the future; used is a fact about the past. The just-in-case thing, a plausibly useful object kept for a someday that rarely comes, is the hardest clutter to see because each piece is defensible.

The hero tool is the Use Test: when did you last use it? A fast, specific memory means necessary, and it stays. A shrug means unnecessary, and it goes in the out box, a set-aside spot, not a destination. A tiebreaker handles hard cases: if it vanished today, would you buy it again? A companion move clears duplicates and surplus: keep your favorite, retire the understudy. A worked pass through the basket shows the move, and an anti-shame section undoes the sunk-cost pull: letting go is not wasting. The friction meter takes an honest second, smaller step, still short of the goal.
