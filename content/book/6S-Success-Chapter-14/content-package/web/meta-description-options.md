   Note: 154 characters.

3. You were the label, so the room only held together when you were home. A visual control moves the rule onto the shelf, where anyone can read it at a glance. (156)

   Note: 156 characters.

4. Label the spot, not just the thing. A label, an outline, or a boundary makes each home explain itself, so guests and kids can put things back without asking. (157)

   Note: 157 characters.

5. Make your home self explaining. Give each already-placed spot one cue, a label, an outline, or a clear jar, so anyone can put a thing back at a glance. (151)
