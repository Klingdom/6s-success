### 4. Visual brand system

Every visual asset uses the same design system. Built on the book's existing visual language so the LinkedIn presence and the book are visually one product.

#### Color palette

| Use | Color | Hex |
|---|---|---|
| Primary navy (headers, framework borders) | Navy | #2C3E50 |
| Background | White | #FFFFFF |
| Light panel (info boxes) | Gray | #F4F6F7 |
| Border / line | Light gray | #BDC3C7 |
| Action / positive outcome | Green | #196F3D |
| Problem / "before" / anti-pattern | Red | #C0392B |
| Key insight / callout | Amber | #B7950B |
| Definition / context | Blue | #2980B9 |
| Process / sequence highlight | Orange | #E67E22 |
| Quality / data | Purple | #8E44AD |

These match the book's visuals exactly. Each carousel, infographic, and image post pulls from this palette.

#### Typography
- **Headings:** Calibri Bold (Arial fallback)
- **Body:** Calibri Regular
- **Captions:** Calibri Italic, gray (#555555)
- All caps used only for category labels (PHASE 1, BEFORE, AFTER) — never for body copy

#### Layout patterns (the four standard visual templates)

**Template A — The Framework Card**
Used for numbered models, multi-step processes, comparison frames.
- Title at top + italic tagline beneath
- 3–6 colored boxes or columns showing the framework
- Bottom callout box: one-sentence takeaway
- Examples: FMEA process flow, 6S cycle, Continuous Flow evolution

**Template B — The Before/After**
Used for transformation stories, anti-pattern fixes.
- Top half (red): the "before" state
- Bottom half (green): the "after" state
- Side annotation showing the cause of the change
- Examples: SMED internal/external, batch vs. one-piece flow

**Template C — The Calculator**
Used for formulas, math reveals, surprising ratios.
- Formula in a centered box at top
- Step-by-step worked example below
- Bottom box: "what this number tells you"
- Examples: TAKT calculation, RPN calculation, Pareto threshold

**Template D — The Anatomy**
Used for annotated examples (control plans, backlog items, charters).
- Full artifact rendered on the left or top
- Numbered callouts pointing to the key parts
- Right or bottom: the legend explaining each callout
- Examples: control plan anatomy, backlog item anatomy

#### LinkedIn-specific specs

| Asset | Aspect ratio | Dimensions | Notes |
|---|---|---|---|
| Single image post | Square | 1080 × 1080 | Maximum visibility in feed |
| Framework infographic | Portrait | 1080 × 1350 | More screen real estate |
| Document carousel | Portrait PDF | 1080 × 1350 per page | 6–10 pages, never more |
| Native video | Vertical | 1080 × 1920 | 60–90 sec, captions burned in |
| Quote graphic | Square | 1080 × 1080 | High contrast, large text |

#### Accessibility (non-negotiable)
- Alt text on every image — describe the visual content, not just "framework diagram"
- Minimum 16pt body text on any image
- Color is never the only signal — pair color with shape or label

### 5. The Chapter Decomposition Framework

This is the recipe applied to every chapter you upload. It converts a chapter into a complete content bundle in a single pass.

#### Step 1 — Extraction (the five content unit types)

I read the chapter and extract every content unit, classified by type:

| Unit type | Definition | Becomes |
|---|---|---|
| **Frameworks** | Numbered models, multi-step processes, structured comparisons | Carousels (Template A) |
| **Concepts** | Single ideas worth one post each | Single-image posts (Template C or D) |
| **Anti-patterns** | What teams get wrong, common mistakes | Short text posts |
| **Worked examples** | The method applied in practice | Long-form essays |
| **Quotables** | Lift-able lines — one-sentence insights | Quote graphics |

Each unit gets scored on three criteria, 1–5:
- **Relatable:** Will the reader immediately recognize the problem?
- **Surprising:** Does this challenge a default assumption?
- **Actionable:** Can they do something with this on Monday morning?

Units that score 12+ go into production. Units that score below 12 go into the deferred backlog (still useful as comment material or for later refinement).

#### Step 2 — Mapping (units to formats)

Each chapter produces a standard bundle:

| Output | Quantity per chapter | Source units |
|---|---|---|
| Anchor carousel | 1 | The chapter's main framework |
| Framework infographic | 1 | The chapter's "one image to save" |
| Single-image posts | 3–4 | High-scoring concepts |
| Long-form essay | 1 | Best worked example |
| Short text posts | 3–4 | Anti-patterns and quotables |
| Video script | 1 | The chapter in 60–90 seconds |
| Quote graphics | 2–3 | Top quotables |

**Total per chapter: 12–16 publishable pieces.** Enough for 4 weeks at 3 posts/week.

#### Step 3 — Sequencing (the release wave)

Each chapter is released as a 4-week wave on LinkedIn. The wave has a story arc:

**Week 1 — Hook the pain**
- Mon: Single-image post #1 (concept that resonates with the chapter's core pain)
- Wed: Short text post (anti-pattern)
- Fri: Single-image post #2 (a second angle on the same pain)

**Week 2 — Reveal the framework**
- Mon: Anchor carousel (the framework breakdown — high savability)
- Wed: Quote graphic (lift-able line from the chapter)
- Fri: Single-image post #3 (a tool or technique)

**Week 3 — Show it working**
- Mon: Long-form essay (worked example, 400–800 words)
- Wed: Short text post (a second anti-pattern)
- Fri: Single-image post #4 (a detail from the worked example)

**Week 4 — Recap and bridge**
- Mon: Framework infographic (the chapter on one image — the lead magnet asset)
- Wed: Native video (60–90 sec talking head)
- Fri: Short text post that bridges to next chapter's pain

This structure repeats for every chapter. Predictable for the audience, easy to produce.

Each chapter handoff produces these artifacts in a single zipped bundle:

### 6. Output format catalog

Reference spec for every LinkedIn format. Pin this — every piece of content you produce maps to one of these.

#### Format 1 — Single-image post
- 1080 × 1080 square
- 60–80 words of caption
- Caption structure: hook → setup → insight → implied CTA
- One concept per post, never more
- Used 2–3x per week

#### Format 2 — Carousel (LinkedIn Document)
- 6–10 portrait pages (1080 × 1350), uploaded as PDF
- Slide 1: hook + tease ("Most teams skip this step. Here's why that's expensive.")
- Slides 2–N: the framework or breakdown
- Final slide: "Save this" + a one-line CTA
- Used 1x per week, anchor of the chapter wave
- Highest savability — drives followers and DMs

#### Format 3 — Framework infographic
- 1080 × 1350 portrait, single image
- The whole chapter on one image
- Designed to be saved and re-shared
- Used 1x per chapter as the wave finale and as lead-magnet preview
- Highest re-share rate

#### Format 4 — Long-form essay
- 400–800 words native LinkedIn post (not an Article — they convert worse)
- Worked example structure: situation → problem → method applied → outcome → principle
- One single image at the top to break up the wall of text
- Used 1x per chapter, in Week 3 of the wave
- Drives the deepest DM conversations

#### Format 5 — Short text post
- Under 80 words, no image
- Hook + 2-3 line punch
- Used for anti-patterns, contrarian takes, observations
- Used 2-3x per week

#### Format 6 — Native video
- 60–90 second talking head, vertical 1080 × 1920
- Burned-in captions (LinkedIn auto-captions are unreliable)
- Hook in first 3 seconds
- Used 1x per chapter
- Boost from the algorithm, useful for trust

#### Format 7 — Quote graphic
- 1080 × 1080 square
- High contrast, large text, minimal decoration
- One sentence pulled from the chapter
- Used as filler in busy weeks or as comments on other people's posts
- Lowest production cost, surprisingly high engagement

## Part C — The Content Calendar

### 7. The 12-month book rollout

The book has 8 chapters + an 11-topic appendix + a glossary. Released as content waves, this is ~10 months of structured content. Then 2 months of evergreen / community / case-study content to close out the year.

Order matters. Lead with the pillars that drive the most pain-recognition, then build credibility, then sell the format.

| Month | Wave | Focus | Why this order |
|---|---|---|---|
| **1** | Onboarding wave | Profile refresh, pillar primer, lead-magnet launch | Build the foundation before publishing book content |
| **2** | Ch. 5 — Measure Process | The Hidden Math of Time pillar | Most surprising, highest stop-the-scroll factor |
| **3** | Ch. 4 — Define Process | The Gap pillar | Most relatable pain, sets up the rest of the methodology |
| **4** | Ch. 6 — Analyze Process | Tools Used Correctly | Demonstrates technical depth — filters serious leads |
| **5** | Ch. 7 — Improve Process | The Event Format | Sells the engagement structure |
| **6** | Appendix waves (1/3) | 6S + Standard Work + Visual Controls | Foundational Lean — broadens reach |
| **7** | Ch. 1 — Identify Opportunity | The Event Format + The Gap | How real engagements get scoped |
| **8** | Ch. 2 — Charter Project | Tools Used Correctly | Project framing, financial benefits |
| **9** | Ch. 3 — Kickoff Project | The Event Format | Logistics of running a real event |
| **10** | Appendix waves (2/3) | TAKT + SMED + Continuous Flow | Operations leaders gold |
| **11** | Appendix waves (3/3) + Glossary nuggets | Control Plans + JIT + TPM | Sustaining the Gains pillar finale |
| **12** | Case study + community + recap | Real client work (anonymized) + 2026 retrospective | Year-end momentum + 2027 setup |

**Why this isn't strictly chapter-1-first:** The book's chapters are organized for facilitators executing an event in order. LinkedIn content is organized for *strangers in the feed*. Lead with the most striking insight (the 98% lag-time stat), not the project-management opener. Build outward from there.

#### Interleaved evergreen content
Within each wave, every Friday's post can be a "free" slot — a contrarian take, a current-event hot take applied through a Lean lens, a community question. This keeps you reactive and human, not just promotional.

## Part D — Execution and Operations

### 9. Engagement plays

70% of consulting leads from LinkedIn come from comments and DMs, not from the post itself.

#### Comment strategy
- 20 minutes per posting day commenting on posts from 10–15 ICP people
- Substantive comments only — add a Lean angle, share a counter-example, ask a precise question
- Avoid "Great post!" — it signals low value
- Comment on your own post 1–2 hours after publishing

#### Following strategy
- 5 new ICP people per posting day → 200 new connections in 90 days
- Never connect cold. Like → comment → connect, in that order

#### DM strategy
When someone in your ICP comments or reacts to multiple posts:

> Hey [name] — appreciated your comment on [topic]. Curious — is [pain point from their context] something you're actively working on, or just thinking about? Happy to share what I've seen work in similar setups, no pitch.

Three things this does: references them specifically, names a pain, gives them an exit. The "no pitch" tag does heavy lifting.

#### Funnel math
- DM → 20-min discovery call (Calendly)
- Call → scoped proposal (PDF within 48 hours)
- Proposal → engagement

Aim: 1 call per 15 DMs · 1 engagement per 4 calls · ~60 DMs per quarter = 1 solid engagement at start, compounding.

### 12. Quality bar, definition of done, and monthly Kaizen

#### Definition of done — for any single piece of content
Before scheduling, every piece must pass:

- [ ] Maps to exactly one pillar
- [ ] Maps to exactly one content unit type (framework / concept / anti-pattern / example / quotable)
- [ ] Visual (if any) follows the brand system — colors, typography, template
- [ ] Hook lands in the first sentence — no warm-up
- [ ] No emojis · no hashtag stuffing · no "thoughts?" closer
- [ ] Passes the COO Coffee Test — *would I say this to a COO over coffee?*
- [ ] Alt text written for any image
- [ ] Scheduled to the correct day in the release wave

#### Definition of done — for a chapter bundle
Before publishing the first post of a wave, the bundle must include:

- [ ] 1 anchor carousel (PDF, 6–10 pages)
- [ ] 1 framework infographic (PNG)
- [ ] 3–4 single-image posts with captions
- [ ] 1 long-form essay
- [ ] 3–4 short text posts
- [ ] 1 video script (production optional — script always)
- [ ] 2–3 quote graphics
- [ ] 4-week release calendar with dates
- [ ] Engagement hooks document — anticipated comments and your responses

#### The content kanban
Each piece of content moves through these states. Track in a simple Trello/Notion board.

| State | Definition | WIP limit |
|---|---|---|
| **BACKLOG** | Identified as a content unit; not yet in production | unlimited |
| **IN PRODUCTION** | Copy drafted, visual being built | 5 |
| **READY** | Drafted, reviewed, passes Definition of Done | 12 |
| **SCHEDULED** | Queued in LinkedIn or buffer with date | 12 |
| **PUBLISHED** | Live, monitoring engagement (3 days) | — |
| **REVIEWED** | Post-publish retrospective complete, metrics logged | — |

#### The monthly retrospective — Kaizen applied to itself
First Sunday of each month, 45 minutes. Apply the same retrospective format the book teaches:

**What went well**
List the 3–5 posts that drove the most DMs, saves, and meaningful comments. What did they have in common? Visual style? Pillar? Format? Time of day?

**What didn't**
List the 3–5 posts that underperformed. Were they off-pillar? Bad hook? Wrong format for the content type? Posted at the wrong time?

**What we'll change**
For each item in "what didn't," name a specific change for next month. Add it to the calendar.

Capture the retrospective notes. After 6 months you have a personal playbook — *which posts work for your audience specifically*, not generic LinkedIn advice.

**This is the meta-move:** you teach Kaizen, and you run your own marketing as a continuous Kaizen. That story itself becomes content.
