# Content Package: Chapter 1, Why Some Homes Feel Effortless

This folder is a complete content and packaging workflow for Chapter 1 of *6S Success: Home Edition*. One chapter, turned into a full set of assets for web, social, email, video, audio, slides, print, and graphics.

## What is in here

| Folder | What it holds |
|--------|---------------|
| `canonical/` | The single source of truth: title, summary, outline, key takeaways, quotes, CTAs, SEO notes, and metadata JSON. Every other asset is built from these. |
| `web/` | SEO titles, meta descriptions, Open Graph copy, schema.org JSON-LD, landing-page intro, navigation copy, read-next recommendations. |
| `linkedin/` | Long article, 10 short posts, carousel outline, newsletter version, comment prompts. |
| `facebook/` | 5 conversational posts, one longform post, one group discussion post. |
| `x/` | One thread and 10 standalone short posts. |
| `newsletter/` | Full newsletter, 10 subject lines, 10 preview-text options, a short teaser. |
| `video-audio/` | YouTube script (6 to 8 min), 5 short-video scripts, podcast script (8 to 12 min), teleprompter script, b-roll and visual notes. |
| `slides/` | Teaching deck outline, LinkedIn carousel copy, visual storyboard. |
| `pdf-ebook/` | Chapter PDF front matter, ebook description, sales copy, back-cover copy, 10 discussion questions. |
| `graphics/` | One infographic spec, 10 quote cards, 5 diagram ideas, 5 image-generation prompts. |
| `workflow/` | This file, plus the production checklist, publishing calendar, repurposing map, and asset inventory CSV. |
| `review/` | Editorial review, brand-voice check, reuse-risk check, and the final package summary. |

## How to use it

1. Start in `canonical/`. Confirm the title, slug, and metadata match your live book.
2. Read `workflow/repurposing-map.md` to see how the chapter becomes each asset.
3. Follow `workflow/publishing-calendar.md` for a 14-day rollout.
4. Track work in `workflow/asset-inventory.csv`.
5. Before publishing, read everything in `review/`.

## Important note on the source files

The Word manuscript and the PDF are an EARLIER draft of this chapter, titled "The Day Everything Went Missing." The final HTML is newer and titled "Why Some Homes Feel Effortless." This package was built from the final HTML as the source of truth. The two share themes (morning chaos, friction, "the problem was the system, not the people"), but the HTML is the evolved final version. There was also no separate signature or brief file for Chapter 1, so signature-level details were inferred from the HTML structure. See `review/final-package-summary.md` for details.

## House rules used throughout

- No em dashes.
- Plain, warm, kind voice. The chapter's job is to remove guilt, not to scold. No corporate filler, no hype verbs.
- Every social post is useful on its own, with a soft CTA to the chapter or online book.
- Nothing is invented beyond the chapter. Inferences are labeled.
