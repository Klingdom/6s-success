# Read Next Recommendations: Chapter 10, Red Tags, Holding Areas, and Sorter's Remorse

1. Chapter 11, What to Donate, Sell, Store, Recycle, or Throw Away
   The next step. The maybes now have a system and the second thoughts are handled, so the last loose end is the out box itself, finally full and settled. Next you route it to where each thing should truly go.

2. Chapter 9, Necessary vs. Unnecessary
   The setup. Before this chapter could work, you ran the Use Test and made the clear keep-and-release calls, which left the honest maybes you could not decide and the out box waiting in the corner. This chapter picks up exactly those two loose ends.

3. Red-tag one maybe (the chapter action)
   Pick up one thing you honestly cannot call. On a slip of tape write what it is and a decide-by date, stick it on, and set it in one spot out of the way. If you reach for it before the date, it stays. If not, the decision already made itself.

4. The Red Tag (free resource)
   A printable of the three lines, what it is, the date you tagged it, and a decide-by date, several tags to a sheet, so a maybe gets a proper tag in seconds.

5. The Holding Area card (free resource)
   A printable on how to set up a time-boxed holding area, pick a decide-by date by item type (about a month for everyday, a season for seasonal), and keep the appointment when the date comes up.
