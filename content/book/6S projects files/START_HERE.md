# START HERE — Setting Up the "6S Success" Project

I cannot create the project for you from here (creating a project is something you do in the Claude interface), but everything is packaged so it takes about two minutes.

## The 4 steps

1. **Create the project.** In Claude, open **Projects** in the left sidebar (or go to claude.ai/projects) and click **+ New Project**. Name it **6S Success**. Add a short description like "Writing and designing the book 6S Success: Home Edition." (Note: Claude does not read the project's name or description, so all the real context comes from the steps below.)

2. **Paste the instructions.** Open `6S_Success_PROJECT_INSTRUCTIONS.md`, copy the whole thing, and paste it into the project's **Instructions** field. These apply to every chat in the project.

3. **Upload the knowledge files.** In the project's **Project knowledge** panel, click **+** and add the files in the `knowledge/` folder:
   - `6S_Success_BRIEF.md` (the canonical brief)
   - `6S_Success_DESIGN_SYSTEM.md` (the locked look, fonts, palette, reusable CSS)
   - `6S_Success_PROGRESS.md` (status tracker and decisions)
   - `chapter_01_manuscript.md`, `chapter_01_signature.md`
   - `chapter_02_manuscript.md`, `chapter_02_signature.md`
   - Also upload your original 6S source worksheets when you have them (Principles of 6S, audit forms, etc.).

4. **Start writing.** Open a new chat inside the project and say: **"Continue with Chapter 3."** It will already know the voice, the no-em-dash rule, the three-file workflow, the design system, and where we left off.

## What is in this bundle
- `6S_Success_PROJECT_INSTRUCTIONS.md` — paste into the Instructions field.
- `knowledge/` — upload these to Project knowledge.
- `finals/` — the designed reader-ready chapters (`chapter_01_final.html`, `chapter_02_final.html`). These are deliverables to keep and review. You can keep them out of the knowledge base to save room, since the manuscripts already carry the canonical text and the design-system file carries the look.

## A couple of tips
- Keep `6S_Success_PROGRESS.md` updated at the end of each chapter (or ask Claude to update it) so every new chat picks up cleanly.
- On a paid plan, large knowledge bases switch to retrieval mode automatically, so you can keep adding chapter files as the book grows. On the free plan there is a 5-project limit; this counts as one.
- The HTML finals open in any browser and print cleanly to PDF if you want page proofs.
