# Prompt 13 — Build Observability and AI Operations

## OBJECTIVE

Make production AI behavior measurable.

Track:

- upload success rate
- processing failures
- image analysis latency
- model latency
- model cost
- token consumption
- malformed structured outputs
- room classification confidence
- micro-zone classification confidence
- recommendation acceptance
- recommendation rejection
- correction rate
- Quest completion rate
- before/after upload rate

## DASHBOARDS

### AI Quality

- incorrect room rate
- incorrect micro-zone rate
- hallucination reports
- user correction categories

### Product Usage

- images analyzed
- Quests generated
- Quests completed
- activities completed
- average session length
- popular micro-zones

### Content

- most selected activities
- rarely used templates
- activities with high rejection
- supplies frequently unavailable

## DELIVERABLES

Implement:

- event taxonomy
- metrics
- traces
- structured logging
- cost tracking
- operational dashboards
- alerting thresholds
- privacy-safe analytics
- tests for telemetry emission
