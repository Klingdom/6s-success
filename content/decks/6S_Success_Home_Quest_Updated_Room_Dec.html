6S Success: Home Quest

Updated Whole-Home Room Deck & 15–90 Minute Event Generation Plan

This plan evolves the Entryway Deck into a modular whole-home system where people can add cards by room, micro zone, or 6S activity and then pull, select, assign, or auto-generate cards to create focused 15–90 minute 6S events.

Core design change: The deck is no longer a fixed 90-card experience. It becomes a configurable improvement system. Each room is made of micro-zone mini decks, each micro zone contains 6S actions, and every card can participate in multiple event types.

Entryway source structure retained: Room → Micro Zone → Problem → Tool → Habit → Skill → Upgrade → Win/Reward → Event.

Core Rule

Do not force every room into the same card count. Use 60–70 cards for simpler spaces, 70–100 for normal rooms, and 100+ for complex rooms such as kitchens and garages.

Every Significant Micro Zone Gets Six Core Action Cards

6SQuestionTypical Action
SortWhat does not belong?Remove unused, expired, broken, duplicate, excess, or misplaced items.
Set in OrderWhere should everything live?Assign homes, group by function, use point of use, containers, dividers, and visual locations.
ShineWhat needs cleaning and inspection?Clean while checking for damage, leaks, wear, dirt sources, and maintenance needs.
SafetyWhat could hurt someone or damage the home?Remove hazards, secure chemicals, improve lighting, prevent falls, control water, protect children and pets.
StandardizeHow do we make the correct condition obvious?Labels, min/max, checklists, visual controls, photos, ownership, container standards.
SustainWhat keeps it working?Daily reset, weekly audit, reorder trigger, habit stack, monthly purge, seasonal rotation.
Scale opportunity: 200 whole-home micro zones × 6 core actions = roughly 1,200 core actionable cards, but each household only assembles the cards relevant to its own rooms and routines.

15–90 Minute 6S Event Builder

The central gameplay loop becomes event creation. Users can start by time, micro zone, 6S activity, problem, room, or random draw.

Six Standard Event Lengths

EventTimeBest Use
Quick Win15 minOne visible improvement or one small problem
Mini Quest20 minOne small micro zone
Power Reset30 minOne meaningful micro zone
Focused Event45 minFull 6S on a small or medium zone
6S Event60 minMajor micro zone or several small zones
Room Kaizen90 minMulti-zone room transformation

Five Ways to Generate an Event

  1. By Micro Zone: “Fix my bathroom vanity for 30 minutes.”
  2. By 6S Activity: “Give me a 30-minute Sort event.”
  3. By Problem: “My kitchen counters are out of control.”
  4. Random Draw: “Give me a 20-minute Home Quest.”
  5. Assigned or Self-Selected: Another person assigns cards, or the player voluntarily chooses them.

Card Selection, Pulling, Assignment & Filtering

Three Primary Ways to Populate an Event

PULL
Shuffle eligible cards and draw a random challenge. Best for game energy and reducing decision fatigue.
SELECT
Browse eligible cards and voluntarily choose the work that matters most. Best for autonomy and real household priorities.
ASSIGN
A parent, partner, roommate, coach, or team leader assigns cards. Best for shared ownership and family coordination.

6S-Focus Events Across Multiple Rooms

A player can choose one S instead of one location. Example: SORT for 30 minutes.

  • Pantry: Expired Food
  • Refrigerator: Mystery Leftovers
  • Bathroom: Expired Toiletries
  • Closet: Unworn Clothes
  • Entryway: Seasonal Overflow
Design principle: The same physical card should be able to participate in different event types. A single card may be useful in a micro-zone event, a room event, a 6S-focus event, a random event, or an assigned event.

Problem Cards Become Event Triggers

Example: Mail Avalanche can trigger a 15-minute Paper Purge and direct the player to pull:

  • Mail Station
  • Sort
  • Mail Sorter
  • Sort Mail Daily

Tool Cards Become Countermeasures

When an event reveals a system gap, the player chooses a countermeasure path:

  • Own It — use something already available.
  • Improvise It — repurpose a household item.
  • Buy It — purchase an organizer or tool.
  • 3D Print It — print a compatible solution.
  • Skip It — continue without adding equipment.

Every Event Produces Standard Outputs

  1. Before: What was wrong?
  2. Actions: What cards were completed?
  3. After: What changed?
  4. Standard: What is the expected condition now?
  5. Sustain: What tiny behavior keeps it that way?

Key rule: Every event must leave behind an improved system, not just a temporarily cleaner area.

Production Framework, App Integration & Master Gameplay Loop

Production Sequence for Every New Room

  1. Define the room mission.
  2. Map 8–15 primary micro zones.
  3. Run the 6S matrix against every micro zone.
  4. Identify failure modes and recognizable problems.
  5. Identify countermeasures, tools, labels, and visual controls.
  6. Define standard work and Sustain habits.
  7. Extract only the strongest card opportunities.
  8. Create relationships between cards.
  9. Assign time, difficulty, people, and event tags.
  10. Validate that cards can generate 15–90 minute events.
