## Recommended Usage

Use Prompt 00 as the repository-level `CLAUDE.md` or merge it into your existing project instructions.

Use Prompts 01–13 to build the main platform capabilities.

Use Prompts 14–18 repeatedly during development and maintenance.

Use Prompt 19 as an architecture guardrail when reviewing larger features.

## Core Principle

Do not build hundreds of bespoke room prompts.

Build a reusable system:

**Micro-Zone Taxonomy + 6S Activities + Instruction Blocks + Supplies + Organization Patterns + Safety Rules + Vision Observations + Recommendation Rules + AI Personalization + User Corrections**
