# Prompt 16 — Add a New Room or Micro-Zone Super Prompt

Use whenever expanding the Home Quest ecosystem.

## INPUT

New room or micro-zone:

`[INSERT NAME]`

## TASK

Do not simply add the new name.

Analyze how this new micro-zone fits the existing knowledge system.

Determine:

- parent room
- parent micro-zone
- archetypes
- primary functions
- common objects
- common surfaces
- common storage
- applicable activity templates
- required new activities
- applicable instruction blocks
- required new instructions
- applicable supplies
- new supplies genuinely required
- organization patterns
- safety rules
- standard templates
- sustain routines
- vision recognition hints

Follow the reuse rule:

**Reuse existing content wherever possible.**

Only create new entities when existing entities cannot accurately represent the requirement.

Create or update tests.

## OUTPUT

Report:

- reused entities
- newly created entities
- schema changes, if any
- migration/seed changes
- tests
- content gaps discovered
